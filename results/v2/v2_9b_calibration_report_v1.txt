ROOT CAUSE
  Under locked V2-3 generator-holdout evaluation, the same 923 REAL_VALIDATION image IDs appear in EVERY fold's prediction file. Preferred leave-one-fold-out calibration therefore has source Real rows that are exact ID duplicates of the target fold Real set. Leakage gate removes those IDs from FITTING ONLY, which removes ALL Real negatives from every calibrator fit set, leaving AI-only scores. Binary post-hoc calibration (temperature / Platt) cannot be fitted scientifically without Real labels. Protocol forbids inventing another split, using target-fold labels, or replaying V2-7 / train inference to obtain alternate scores.
